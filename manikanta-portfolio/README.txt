Preview:
1. Extract the ZIP.
2. Open index.html in any modern browser.

Publish free with GitHub Pages:
1. Create a repository named manikantajanga.github.io (or use an existing portfolio repo).
2. Upload index.html to the repository root.
3. In GitHub, open Settings > Pages and select Deploy from a branch > main > /(root).
4. Save and wait for the published URL to appear.
